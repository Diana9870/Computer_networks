## Домашнє завдання №1

### Завдання 1. Дослідження мережі

Для дослідження мережевих інтерфейсів використана команда:

```bash
ip a
```

* Результат виконання команди

```text
1: lo: <LOOPBACK,UP,LOWER_UP> mtu 65536 qdisc noqueue state UNKNOWN group default qlen 1000
    link/loopback 00:00:00:00:00:00 brd 00:00:00:00:00:00
    inet 127.0.0.1/8 scope host lo
       valid_lft forever preferred_lft forever
    inet 10.255.255.254/32 brd 10.255.255.254 scope global lo
       valid_lft forever preferred_lft forever
    inet6 ::1/128 scope host
       valid_lft forever preferred_lft forever
2: eth0: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 qdisc mq state UP group default qlen 1000
    link/ether 00:15:5d:5c:93:7c brd ff:ff:ff:ff:ff:ff
    inet 172.24.15.130/20 brd 172.24.15.255 scope global eth0
       valid_lft forever preferred_lft forever
    inet6 fe80::215:5dff:fe5c:937c/64 scope link
       valid_lft forever preferred_lft forever
```

* Аналіз результату

Основним мережевим інтерфейсом є `eth0`. Він використовується для мережевого підключення Linux-середовища WSL.

- Інтерфейс: `eth0`
- Тип підключення: Ethernet
- MAC-адреса: `00:15:5d:5c:93:7c`
- IP-адреса: `172.24.15.130`
- Рівень OSI для IP-адреси: 3-й, мережевий
- Маска: `/20`, що відповідає `255.255.240.0`
- Рівень OSI для маски: 3-й, мережевий
- Broadcast: `172.24.15.255`
- Gateway: `172.24.0.1`

IP-адреса `172.24.15.130` є приватною IPv4-адресою. Вона використовується всередині локальної мережі WSL. MAC-адреса `00:15:5d:5c:93:7c` ідентифікує мережевий інтерфейс на канальному рівні. Відповідно до моделі OSI MAC-адреса належить до 2 канального рівня. IP-адреса та маска належать до 3 мережевого рівня моделі OSI, оскільки використовуються для адресації пристроїв та визначення мережі.

* Hosts

Для перегляду локальних відповідностей імен хостів та IP-адрес була використана команда:

```bash
cat /etc/hosts
```

Результат:

```text
127.0.0.1       localhost
127.0.1.1       DESKTOP-E5EPJ14.localdomain     DESKTOP-E5EPJ14

::1     ip6-localhost ip6-loopback
fe00::0 ip6-localnet
ff00::0 ip6-mcastprefix
ff02::1 ip6-allnodes
ff02::2 ip6-allrouters
```

Файл `/etc/hosts` використовується операційною системою для локального зіставлення імен хостів з IP-адресами.

У цьому файлі:

  `127.0.0.1` відповідає імені `localhost`;
  `127.0.1.1` відповідає імені комп'ютера `DESKTOP-E5EPJ14`.

### Завдання 2. Дослідження маршрутизації

Для перегляду таблиці маршрутизації використана команда:

```bash
ip r
```

* Результат виконання команди

```text
default via 172.24.0.1 dev eth0 proto kernel
172.24.0.0/20 dev eth0 proto kernel scope link src 172.24.15.130
```

* Аналіз результату

З результату команди можна визначити такі параметри:

- Gateway: `172.24.0.1`
- Мережевий інтерфейс: `eth0`
- Локальна мережа: `172.24.0.0/20`
- IP-адреса джерела: `172.24.15.130`
- Протокол маршруту: `kernel`

Рядок:

```text
default via 172.24.0.1 dev eth0 proto kernel
```

означає, що для маршрутів за замовчуванням використовується шлюз `172.24.0.1`, а передача даних здійснюється через мережевий інтерфейс `eth0`. Позначення `proto kernel` означає, що цей маршрут встановлений ядром Linux.

Другий рядок:

```text
172.24.0.0/20 dev eth0 proto kernel scope link src 172.24.15.130
```

показує маршрут до локальної мережі `172.24.0.0/20`, яка доступна безпосередньо через інтерфейс `eth0`.

### Завдання 3. Знаходження публічної IP-адреси

Для визначення публічної IP-адреси використана команда:

```bash
curl ifconfig.io
```

* Результат виконання команди

```text
178.74.229.24
```

* Порівняння локальної та публічної IP-адрес

Локальна IP-адреса:

```text
172.24.15.130
```

Публічна IP-адреса:

```text
178.74.229.24
```

Локальна IP-адреса `172.24.15.130` використовується всередині приватної мережі WSL і не є адресою, яка безпосередньо ідентифікує комп'ютер у глобальній мережі Інтернет.

Публічна IP-адреса `178.74.229.24` використовується для зв'язку з Інтернетом. Вона надається провайдером і є адресою, яку бачать зовнішні Інтернет-сервіси.

Домашній роутер виконує роль посередника між локальною мережею та Інтернетом. Він може використовувати технологію NAT (Network Address Translation), яка дозволяє пристроям із приватними IP-адресами виходити в Інтернет через одну публічну IP-адресу. У моєму випадку додатково використовується WSL, тому адреса `172.24.15.130` належить мережевому середовищу WSL. Під час звернення до Інтернету зовнішні сервіси бачать публічну адресу `178.74.229.24`.

### Висновок

У результаті виконання команд було досліджено мережевий інтерфейс `eth0`, визначено його MAC-адресу, локальну IP-адресу, маску та broadcast-адресу. Також було визначено шлюз за замовчуванням `172.24.0.1` та досліджено таблицю маршрутизації. Публічна IP-адреса `178.74.229.24` відрізняється від локальної IP-адреси `172.24.15.130`, оскільки локальна адреса використовується у внутрішній мережі, а публічна для доступу до ресурсів глобальної мережі Інтернет.
